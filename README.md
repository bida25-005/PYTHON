# PYTHON

Sections A and B. 
Section A asks for student names and one grade for each student, then finds the class total and average. Section B lets you enter at least three subjects and grades for each student. It shows each student's average, the highest and lowest mark in each subject, and a summary of the marks.

Section C. 
It uses a dictionary, which is like a labelled box for keeping information. Its menu lets you add a student, add more grades, remove a student, look at grades for a subject, and search for a student. It also works out the average when you search.

Section D.
It uses functions, which are small named parts of a program that do jobs. The menu can add, search for, and show students, update grades, and display a class summary. It checks that names and marks are entered in a sensible way.

Sections E and F.
These sections use classes to organise students and the gradebook. They can add, find, and remove students, add grades, show student details, and sort students by name or average. They also handle some mistakes, such as a mark that is not a number or a student who cannot be found.
